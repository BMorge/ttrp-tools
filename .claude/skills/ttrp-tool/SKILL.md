# Инструмент TtRP

## 1. Сориентироваться

- Прочитать `AGENTS.md` (ограничения) и `docs/best-practices.md`. Протокол — `docs/protocol.md`, только если нужен метод или событие, которого нет в шаблоне.
- Существующий инструмент: `<id>/tool.manifest.json`, `<id>/src/main.ts` (подключение и события), `<id>/src/state.ts` (схема состояния).
- Образцы: `template/` — минимальный каркас; `dice/` — динамическая загрузка движка, пауза свёрнутого окна, частичный переброс, физика в тестах.

## 2. Новый инструмент

1. `npm run create-tool -- <id> "Название"` — `id`: латиница в нижнем регистре, цифры, дефис; совпадает с папкой и URL.
2. Манифест: `description`, размеры окна (`width`/`height` не меньше `minWidth`/`minHeight`), `requestedCapabilities` — только нужные (сейчас реализована лишь `LOCAL_STATE`).
3. Заменить заметку шаблона своей логикой, сохранив каркас `src/main.ts`: `connectToHost` → `state.load` → `createAutosave` → `client.subscribe`.

## 3. Реализация

- Логика — в чистых модулях без DOM с тестами `*.test.ts` рядом.
- Состояние — zod-схема в `src/state.ts`: `STATE_SCHEMA_VERSION`, `initialState`, `restoreState` (проверка и сброс с флагом `reset`), `toSnapshotState`. Меняется формат — +1 к версии в коде и к `storageSchemaVersion`, миграция в `restoreState`, тест миграции.
- После каждого изменения состояния — `autosave.schedule()`.
- События: `VISIBILITY_CHANGED` → пауза; `CLOSE_REQUESTED` → `autosave.flush()` и `lifecycle.closeReady`; `SESSION_REVOKED` → `autosave.dispose()`, остановить всё и больше не сохранять.
- Тяжёлые зависимости — `await import()` после подключения.
- Интерфейс: кнопки `type="button"` и `keydown` вместо форм; `textContent` вместо `innerHTML`; русский язык; статусы в `role="status"`.
- Фатальная ошибка — понятное сообщение пользователю, затем `lifecycle.reportError` с `fatal: true`.

## 4. Проверка

1. `npm run check` — типы, тесты (включая проверку манифестов), сборка; размер сборки — в выводе.
2. `npm run dev` → <http://localhost:5180>, выбрать инструмент и пройти сценарии, следя за журналом bridge справа и консолью:
   - запуск → «Запустить заново» → состояние восстановилось;
   - «Скрыть окно» → анимации и таймеры на паузе → «Показать окно»;
   - «Закрыть окно (USER_CLOSE)» → `lifecycle.closeReady ✓` в журнале раньше таймаута;
   - «Уйти из раздела (NAVIGATION)» → «Запустить заново» → сохранённое на месте;
   - «Отозвать сессию» → инструмент остановлен, новых `state.save` нет;
   - снять `LOCAL_STATE`, затем лимит 1024 байта → инструмент работает и сообщает об ограничении.
   Если есть браузерные инструменты — пройти сценарии самому и приложить скриншот.
3. Собранная версия: `npm run build -- --host-origins http://localhost:5180`, `npm run serve` и `npm run dev -- --host-only`.

## 5. Перед PR

- Чек-лист `docs/connecting.md` §2; новая версия существующего инструмента — увеличенная `version`.
- В описании PR: что сделано, как проверить, размер сборки, новые зависимости и их лицензии.
- Отметки о принятии CLA и условий подключения ставит человек — агент их не отмечает.
