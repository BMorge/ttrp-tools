# Правила для ИИ-агентов — TtRP Tools

Репозиторий встраиваемых инструментов сервиса Time to Roleplay (TtRP): SDK (`sdk/`), песочница (`dev-host/`), пример (`dice/`), шаблон (`template/`), скрипты (`scripts/`). Обзор — `README.md`, устройство — `docs/architecture.md`.

## Порядок работы

1. Определите, что меняется: инструмент (`<id>/`), SDK, песочница, скрипты или документация.
2. Инструмент — по `docs/best-practices.md` (для Claude — skill `ttrp-tool`). Новый создаётся только командой `npm run create-tool -- <id> "Название"`.
3. SDK и протокол — по `docs/protocol.md`: схемы `sdk/protocol.ts`, хост и клиент меняются вместе с `sdk/bridge.test.ts` и `docs/protocol.md`. Несовместимое изменение — только с новой `bridgeVersion`.
4. Проверка — `npm run check`; изменения поведения окна — ещё и сценарии песочницы из `docs/connecting.md` §2.

## Ограничения инструмента

- Связь с сайтом — только через `@tools-sdk/client`. Никаких сетевых запросов наружу, CDN и внешних шрифтов.
- Без `<form>`, `window.open`, `alert`/`confirm`/`prompt`, скачиваний, `eval`/`new Function`, перезагрузки документа.
- Данные из `state.load` проверяются схемой; вывод данных — через `textContent`/`value`, не `innerHTML`.
- Версия схемы в `src/state.ts` равна `storageSchemaVersion` манифеста; каждое выпускаемое изменение — новая `version`.
- Импорты — только из своей папки, `@tools-sdk/*` и npm-пакетов с разрешительной лицензией (MIT, BSD, Apache-2.0, ISC).

## Конвенции

- Интерфейс и документация — на русском; код, идентификаторы и комментарии — на английском.
- TypeScript strict, именованные экспорты; импорты группами через пустую строку: внешние → `@tools-sdk/*` → относительные.
- Тесты Vitest рядом с кодом (`*.test.ts`); логика — в чистых модулях без DOM.
- Репозиторий публичный: не добавляйте ключи, токены, внутренние адреса, `dist/` и `node_modules/`.
- Юридические отметки (CLA, условия подключения) в PR ставит человек, не агент.

## Внутри монорепозитория TtRP

В основном репозитории TtRP эта папка — `front/tools`. Зависимости берутся из `front/node_modules` (`npm install` здесь не запускать), запуск — `npm --prefix front run dev:tools`. Каталог подключённых к сайту инструментов и сборка сайта — вне этой папки (`front/tools-catalog.json`, `front/scripts/`); подключение инструмента — skill `ttrp-connect-tool` основного репозитория.
