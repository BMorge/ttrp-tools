# Как участвовать

Спасибо, что хотите улучшить инструменты TtRP. Здесь — как предложить изменение, чтобы его можно было быстро принять.

## Перед началом

- **Новый инструмент или заметное изменение SDK** — сначала issue: что и зачем. Так мы договоримся о решении до того, как вы потратите время.
- **Исправление ошибки, документация, мелкие улучшения** — сразу pull request.
- **Уязвимость** — не в issue, а по [SECURITY.md](SECURITY.md).

## Pull request

1. Сделайте форк и ветку от `main`.
2. Новый инструмент — `npm run create-tool -- <id> "Название"`; правила — [docs/best-practices.md](docs/best-practices.md).
3. Перед отправкой — `npm run check` (типы, тесты, сборка) и проверка в песочнице (`npm run dev`).
4. Заполните шаблон PR: что сделано, как проверить, чек-лист, принятие CLA.

Один PR — одна задача. Сообщения коммитов — по [Conventional Commits](https://www.conventionalcommits.org/ru/): `feat(dice): …`, `fix(sdk): …`, `docs: …`.

PR не сливается кнопкой: этот репозиторий — зеркало основного репозитория TtRP. Принятые коммиты переносятся туда с сохранением авторства и появляются здесь со следующей синхронизацией; PR закрывается ссылкой на коммит.

## Права на вклад (CLA)

Вклад принимается только после принятия [Соглашения о предоставлении прав на вклад](legal/cla.md): отметьте пункт о нём в шаблоне PR. Коротко: вы сохраняете права на свой код и предоставляете ООО «ТТРП» безвозмездную неисключительную лицензию на его использование, в том числе в сервисе Time to Roleplay; код в репозитории распространяется по Apache License 2.0.

Если инструмент предлагается для подключения к сайту, примите также [Условия подключения инструментов](legal/tool-terms.md).

Если вы пишете код по работе, убедитесь, что работодатель не возражает: права на служебный код могут принадлежать ему.

## Стиль кода

- TypeScript в строгом режиме, именованные экспорты.
- Идентификаторы и комментарии в коде — по-английски; интерфейс и документация — по-русски.
- Импорты: сначала внешние пакеты, затем `@tools-sdk/*`, затем относительные — группы через пустую строку.
- Инструмент не импортирует код других инструментов и песочницы; общий код — только `sdk/`.
- Изменения протокола — вместе с тестами в `sdk/bridge.test.ts` и описанием в [docs/protocol.md](docs/protocol.md); несовместимые изменения — только с новой версией bridge.

## Правила общения

Уважайте друг друга: без оскорблений, давления и дискриминации, критикуйте код, а не людей. Сопровождающие вправе удалять сообщения и ограничивать участие тех, кто нарушает эти правила.
